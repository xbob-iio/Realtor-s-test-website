MASTER PROMPT — Профессиональный сайт риелтора
Ты работаешь как senior full-stack developer, software architect, UI/UX designer и security engineer.

Твоя задача — самостоятельно создать полноценный production-ready веб-сайт для риелтора/агентства недвижимости, специализация — аренда квартир в Киеве и Днепре.

Не ограничивайся созданием красивого frontend. Необходимо реализовать рабочую систему с базой данных, API, авторизацией администратора, CRUD квартир, загрузкой фотографий, фильтрами, SEO, безопасностью, cookies, юридическими страницами и адаптивным интерфейсом.

Как я бы запускал это в Claude Code
Лучше не вставлять промт и сразу требовать весь проект одним гигантским ответом. Claude Code эффективнее работает непосредственно с файлами проекта: дай ему этот Master Prompt, а затем попроси выполнять его по этапам, проверяя build, lint и БД после каждого крупного этапа.

И ещё один важный момент: для реального сайта я бы не оставлял логин/пароль администратора в самом промте. Claude должен создать механизм авторизации, а секреты и production-данные должны попасть только в .env/secret manager.
